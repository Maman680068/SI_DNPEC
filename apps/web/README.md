# @dnpec/web

Frontend web du SI DNPEC — **Next.js (App Router, React + TypeScript) + Tailwind
CSS**, avec des composants prêts à l'emploi type shadcn/ui (cahier des charges §7.7).

Ce dossier est un scaffold vide pour l'instant : l'initialisation effective de
l'application Next.js (via `create-next-app` ou équivalent) et l'intégration de
Tailwind + `@dnpec/ui` interviendront après validation du schéma de données
(`apps/api/prisma/schema.prisma`).

Écrans de référence : `docs/maquette_dnpec_finale.html`.
