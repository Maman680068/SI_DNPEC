# @dnpec/ui

Design system partagé entre `apps/web` (Tailwind) et, à terme, `apps/mobile`
(NativeWind).

Contiendra :
- les **tokens de design** (couleurs, typographies) extraits de
  `docs/maquette_dnpec_finale.html` — voir `docs/architecture-proposition.md` §3 ;
- les composants d'interface réutilisables (boutons, cartes, badges de statut/priorité,
  etc.), à construire à partir de la maquette une fois l'architecture de données validée.

Package vide pour l'instant (scaffold uniquement) — aucun composant n'a encore été codé.
