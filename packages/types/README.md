# @dnpec/types

Types TypeScript et DTOs partagés entre `apps/web`, `apps/api` et `apps/mobile`
(rôles, statuts de tâche, niveaux de confidentialité, énumérations métier, etc.),
générés ou synchronisés à partir du schéma Prisma de `apps/api/prisma/schema.prisma`.

Package vide pour l'instant (scaffold uniquement) — sera peuplé une fois le schéma
de base de données validé.
